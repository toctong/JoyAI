# FrameRally 工具目录封面 · 生图提示词

**方向：** 不要棚拍周边实物、不要桌面产品图。  
要 **一张完整动漫立绘 / 插画**，再叠上该工具的视觉效果（拍立得边框、公仔质感、杂志排版……），像「动漫图 × 工具加工」。

参考气质：高细节现代二次元、戏剧光、角色主体清晰、色彩干净有冲击力（类似天使白发 + 彩刃那种完成度），**不是**电商商品静物。

每个工具 **3 张叠卡**：

| 文件 | 叠层 | 画面差 |
|------|------|--------|
| `cover-{slug}-0.webp` | 底层 | 同角色、更远/侧/氛围，可略虚 |
| `cover-{slug}-1.webp` | 中层 | 同角色另一构图或半身 |
| `cover-{slug}-2.webp` | 面层主图 | **最清楚的正面英雄构图** |

横构图 **3:2** · 无水印 · 无 App UI · 无真实商标字 · 避免紫粉霓虹堆砌。  
角色请用 **原创 OC**（勿画明星/知名 IP）。
