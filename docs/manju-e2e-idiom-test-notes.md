## 问题清单（边测边记）

### P0 · 阻断

1. **默认 LLM 空响应**：`script_write` / `analyze_assets` 用 Gemini 2.5 Pro（APIMart）→ `LLM 返回空内容`，阻断帮写与解析资产。切 Qwen Plus 后恢复。
2. **无可用默认渠道时流程不可发现**：失败后输入框长期 disabled，toast/状态不够醒目；用户不知道要去项目设置换模型。

### P1 · 体验/正确性

3. **题材芯片默认「都市情感」**：未点选也会带入 prompt，与成语故事冲突；续写弹层同样默认。
4. **续写钩子漂移**：第 2 集正文结尾是「七月不雨」饥荒钩子，打开第 3 集续写却显示「官征秋赋·加三成」钩子（与正文不一致）。
5. **续写创建后序号错位**：创建第 2 集后弹层立刻变成「第 3 集 / 第 4 集」，且仍展示旧对话与多个「创建为下一集」，易重复建集。
6. **剧集标题冗余截断**：如 `#2-第2集：阿呆执守树桩致田`（标题自带「第2集」+ 列表再标序号）；标题似被截断。
7. **分镜编号跨集累加**：Ep1=`1-1…1-3`，Ep2=`2-4…2-12`，Ep3=`3-13…3-23`，不是每集从 `n-1` 重计。
8. **规划成功但 toast 文案错乱**：点「AI 规划」时弹出「提示词已写回镜头」。
9. **新角色未入库**：续写出现李伯、王婶，资产库仍仅阿呆；分镜「角色 0/1」无法绑定，一致性无保障。
10. **场景/道具恒为 0**：解析失败后无引导补建；写词可不出 `@角色·`（Ep2 部分镜），跨镜人物漂移风险高。

### P2 · 流程缺口 / 效率

11. **无批量生图/生视频**：一镜一确认，Ep2 9 镜 + Ep3 11 镜全量出片成本极高。
12. **制作入口不自动规划**：从「制作视频」进制作台是空分镜，需再点「AI 规划」。
13. **脚本确认闸门**：写词前必须确认脚本（合理），但改对白会再次要求确认，批量迭代时偏重。
14. **预览页范围**：`/preview` 当前主要呈现第 1 集已出片镜头；多集成片预览/选集切换不清晰。
15. **保存偶发断连**：风格保存时短暂 `ERR_CONNECTION_REFUSED`（后端 3001）。
16. **Next.js Issue badge** 常驻；Dev overlay 曾拦截点击。
17. **角色无参考图仍可生图**：流程能走通，但跨镜长相不稳定（产品需强制或强提示）。

### P3 · 次要

## 本轮工程改动（2026-09-30 · 第三批 · 系统稳定性）

全站（不限漫剧）针对「动不动就异常 / 连不上 / 英文 Internal Server Error / `[object Object]`」：

- Nest `AllExceptionsFilter`：未捕获异常统一中文「服务内部错误…」，打日志不泄栈；Zod/校验对象消息可读化
- ValidationPipe / CreateJob Zod：参数错误返回可读中文，不再扔 flatten 对象
- 前端 `api()`：网络闪断 / 502–504 自动重试最多 2 次；`toApiError` 人性化英文 500/网关文案
- Socket：加强重连退避；进程 `unhandledRejection` / `uncaughtException` 打日志
